You are an expert academic curriculum designer for an International School Department. I need you to generate a comprehensive Course Syllabus in strict JSON format. The JSON must match my automated template system exactly.

Please generate a Syllabus for the course: [Insert Course Name here, e.g., AP Microeconomics].

Instructions for JSON fields:
1.  String fields: course_name, semester, instructor, email, grade, credit.
2.  List arrays (must be lists of strings):
* prerequisites_for_the_course * course_description * course_goals * student_learning_outcomes * course_requirements 3.  20-Week Teaching Plan: You MUST generate exactly 20 weeks of content. For each week 1 to 20, create the following flat keys in the root of the JSON object:
* topic1 to topic20
* key_content1 to key_content20
* key_objectives1 to key_objectives20

Output constraints:
Output ONLY valid JSON. No markdown code blocks, no explanations, no trailing commas. If the course is shorter than 20 weeks, fill the remaining weeks with "Final Exams" or "Review" or empty spaces " ".
